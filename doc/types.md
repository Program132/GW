# Types

GW has several data types:
- `Integer`: Integer (ℤ)
- `Number`: Floating-point number (ℝ)
- `String`: Character string (text, messages, etc.)
- `Boolean`: Boolean (true or false)

**Note:** In case of a missing value, you can use 0 for `Integer` and `Number`, `""` for `String`, and `true` or `false` for `Boolean` (depending on your operation).
