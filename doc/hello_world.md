# Hello World

The "Hello World" is a tradition in the programming world. It's a simple program that displays the message "Hello World" on the screen.

## Key Information

- **Comments**: Defined by the `#` character for single-line comments.
- **Printing**: Use `print` to output without a newline, or `println` to include one.
- **Entry Point**: There is no required `main` function; code is executed directly.

## Code

```kotlin
print("Hello World");
```
